## 📌 Sobre o Projeto
O **Cadastro de Usuários** é uma aplicação web que permite registrar, gerenciar e armazenar informações de usuários em um sistema.  
O objetivo principal foi praticar conceitos de **CRUD (Create, Read, Update, Delete)** e consolidar conhecimentos em **React** e **Node.js**.

---

## ✨ Funcionalidades
- 📍 Registro de novos usuários com dados pessoais e de contato.  
- 🔑 Sistema de autenticação simples (usuário/senha).  
- ✏️ Edição e atualização de informações.  
- 🗑️ Exclusão de usuários cadastrados.  
- 📱 Layout responsivo para diferentes dispositivos.
